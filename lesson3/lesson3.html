1. รู้จักกับภาษา Python และการประกาศตัวแปร

ภาษา Python (ไพธอน) เป็นภาษาคอมพิวเตอร์ระดับสูงที่ถูกออกแบบให้อ่านและเขียนง่าย ใกล้เคียงกับภาษาอังกฤษ นิยมนำมาใช้ฝึกเขียนโปรแกรม พัฒนาเว็บไซต์ ปัญญาประดิษฐ์ (AI) และการวิเคราะห์ข้อมูล

ข้อความ (String)

ข้อความที่อยู่ในเครื่องหมายคำพูดเดี่ยวหรือคู่

name = "เด็กชายสมชาย"
จำนวนเต็ม (Integer)

ตัวเลขจำนวนเต็มบวก ลบ หรือศูนย์ ไม่ติดทศนิยม

distance = 15
ทศนิยม (Float)

ตัวเลขที่มีจุดทศนิยม ใช้กับราคาหรือค่าที่ละเอียด

fare = 25.50
2. คำสั่งรับข้อมูล (input) และแสดงผล (print)

การรับค่าและแปลงชนิดข้อมูล

ฟังก์ชัน input() จะรับค่ามาเป็นข้อความ หากต้องการนำไปคำนวณทางคณิตศาสตร์ต้องแปลงเป็นตัวเลขด้วย int() หรือ float()

distance = int(input("กรอกระยะทาง (กิโลเมตร): "))

fare = distance * 8

print("ราคาตั๋วทั้งหมดคือ:", fare, "บาท")

การตัดสินใจด้วย if - elif - else

ใช้เมื่อโปรแกรมต้องการตรวจสอบเงื่อนไขก่อนเลือกทำงาน เช่น การตรวจสอบประเภทผู้โดยสารเพื่อมอบส่วนลด

if passenger_type == "student":

# ลดราคา 50%

discount = 0.5

elif passenger_type == "elder":

# ผู้สูงอายุขึ้นฟรี

discount = 1.0

else:

discount = 0.0

3. ตัวอย่างโปรแกรมสมบูรณ์: ระบบคำนวณค่าตั๋วรถเมล์อัตโนมัติ

ให้นักเรียนคัดลอกโค้ดตัวอย่างด้านล่างนี้ ไปทดลองวางและกดรันใน Online-Python Compiler เพื่อทดสอบการทำงานจริง

                        # --- โปรแกรมจำลองระบบคิดราคาตั๋วรถเมล์ ---
                        base_rate = 10  # ราคาเริ่มต้น 10 บาท

                        # 1. รับค่าระยะทางและประเภทผู้โดยสาร
                        stations = int(input("กรุณาใส่จำนวนสถานีที่เดินทาง: "))
                        passenger = input("ประเภทผู้โดยสาร (general / student / elder): ")

                        # 2. คำนวณราคาตามระยะทาง
                        total_fare = base_rate + (stations * 2)

                        # 3. คิดเงื่อนไขส่วนลด
                        if passenger == "student":
                            total_fare = total_fare * 0.5  # ลด 50%
                            print("ยินดีต้อนรับนักเรียน ได้รับส่วนลด 50%")
                        elif passenger == "elder":
                            total_fare = 0
                            print("ผู้สูงอายุ เดินทางฟรี!")
                        else:
                            print("คิดอัตราค่าโดยสารบุคคลทั่วไป")

                        # 4. สรุปยอดเงิน
                        print("--------------------------------")
                        print(f"ยอดเงินที่ต้องชำระ: {total_fare:.2f} บาท")
                        print("--------------------------------")

โครงสร้างเงื่อนไข if-elif-else ใน Python

ใช้สำหรับตัดสินใจเลือกทำคำสั่งตามเงื่อนไข เช่น การคิดส่วนลดค่าโดยสารตามประเภทผู้โดยสาร:

passenger_type = "student"
dist = 10

if passenger_type == "student":
    price = dist * 1.5 # นักเรียนลดพิเศษ
elif passenger_type == "elderly":
    price = dist * 1.0 # ผู้สูงอายุลด 50%
else:
    price = dist * 2.0 # ราคาปกติ
