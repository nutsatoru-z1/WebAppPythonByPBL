Interactive Learning Roadmap

เส้นทางการเรียนรู้ 3 บทเรียนหลัก

เรียนรู้ทฤษฎีควบคู่การปฏิบัติผ่านมินิเกมและกิจกรรม Interactive โต้ตอบบนเว็บ

บทที่ 1

การแบ่งปัญหาใหญ่เป็นปัญหาย่อย

(Decomposition)

เรียนรู้การย่อยระบบตั๋วรถเมล์ที่ซับซ้อน ออกเป็น 4 ปัญหาย่อย เพื่อให้ง่ายต่อการวิเคราะห์และออกแบบวิธีแก้ไข

วัตถุประสงค์การเรียนรู้:

1. อธิบายความหมายและความสำคัญของแนวคิดเชิงคำนวณและกระบวนการแบ่งปัญหาใหญ่เป็นปัญหาย่อย (Decomposition) ได้
2. วิเคราะห์และจำแนกปัญหาใหญ่ให้เป็นปัญหาย่อยตามสถานการณ์ที่กำหนดได้
3. มีความมุ่งมั่นและกระตือรือร้นในการร่วมกิจกรรมแก้ปัญหา

บทที่ 2

การออกแบบอัลกอริทึม

(Algorithm Design)

การวางลำดับขั้นตอน วิธีการคิดค่ารถเมล์ตามเงื่อนไข ถ่ายทอดออกมาเป็น รหัสลำลอง (Pseudocode) และ ผังงาน (Flowchart)

วัตถุประสงค์การเรียนรู้:

1. อธิบายความหมายและรูปแบบการแสดงอัลกอริทึม (ผังงาน/รหัสลำลอง) ได้
2. ออกแบบอัลกอริทึมในรูปแบบผังงาน (Flowchart) เพื่อแก้ปัญหาที่กำหนดได้
3. มีความมุ่งมั่นและรอบคอบในการออกแบบขั้นตอนวิธี

บทที่ 3

การเขียนโปรแกรม Python

(Python & Web Simulator)

แปลงผังงาน Flowchart เป็นโค้ด Python จริงด้วยคำสั่ง `if-elif-else` และสร้างตัวจำลองเครื่องออกตั๋วรถเมล์

วัตถุประสงค์การเรียนรู้:

1. อธิบายหลักการทำงานของโปรแกรมที่มีการใช้เงื่อนไขในการแก้ปัญหาได้
2. ออกแบบอัลกอริทึมและเขียนโปรแกรมภาษาไพทอนเพื่อคำนวณค่าโดยสารตามเงื่อนไขที่กำหนดได้
3. มีความมุ่งมั่นในการแก้ปัญหาและเห็นประโยชน์ของการนำเทคโนโลยีมาใช้ในชีวิตประจำวัน
